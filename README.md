# うりあげノート

催事販売向けの、スマートフォン対応売上管理Webアプリです。データはブラウザの `localStorage` に保存されるため、サーバーやアカウント登録なしですぐに使えます。

## 起動方法

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。

## 主な機能

- 日付・店舗名・催事名・売上・仕入・歩率・各種経費の登録
- 粗利益・歩率金額・経費合計・最終利益・利益率の自動計算
- 今日／今月の集計、催事別実績、直近6か月の売上グラフ
- 日本円表示、スマートフォン向けレスポンシブデザイン
